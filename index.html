Connect your Google Sheet

How to set this up:
1. Create a Google Sheet with columns: Date, Score (1–10), Note
2. Go to File → Share → Publish to web → choose Sheet1 → Comma-separated values (.csv) → Publish
3. Copy that URL and paste it above, then click Load
4. Your URL will be saved in your browser — no login needed!

To host on GitHub Pages: upload index.html to a repo, enable Pages under Settings, and share the link.
